# Планировка и редактирование

Главная сцена: `Scenes/Levels/DormFloor08.tscn`. Она создаёт этаж по `Data/Floors/floor08.json`.

JSON содержит `floor_id`, `spawn`, `tile_size`, `source_scale` и `zones`. Каждая зона имеет исходный идентификатор Draw.io, подпись, тип, исходный прямоугольник `source` и игровой прямоугольник `rect = [x, y, width, height]`. Меняйте `rect` с шагом 16; `source` оставлен для сопоставления с оригиналом. Изменение `source_scale` само по себе не пересчитывает готовые прямоугольники.

Центральный холл находится в `[160,96,192,384]`. Из него доступны северное и южное вертикальные крылья, западный и восточный коридоры. Две лифтовые находятся справа сверху и слева снизу от холла. На западной стороне холла расположены лоджия и аудитория. Лестничная клетка — севернее холла. Кухни расположены на разных сторонах четырёх крыльев согласно Draw.io.

`FloorManager.gd` разделяет пол, стены, оформление, мебель, интерактивные объекты и UI. Пол отрисовывается из повторяющихся PNG 16×16; стены и крупная мебель имеют StaticBody2D. Персонаж и мебель сортируются по Y. Закрытые жилые блоки отделены внешними коллизиями. Окна закреплены на стенах и не занимают дополнительную проходимую площадь.

Для чистого импорта исходный AudioManager загружает OGG по требованию вместо preload на этапе разбора автозагрузки. Устаревшие внешние UID-подсказки оригинальных сцен убраны; сохранены явные пути к тем же ресурсам. Это устраняет ошибки первого импорта при отсутствии кэша.

Общественные помещения получают перегородку на общей с коридором границе. Дверной проём имеет ширину 32 пикселя. Дверь меняет коллизию и не закрывается, пока в проёме стоит игрок. `DormInteractionManager` выбирает ближайший объект в радиусе 46 пикселей и проверяет прямую видимость физическим лучом. Слой 1 — стены/мебель/двери, слой 2 — игрок; его маска столкновений включает слой 1.

Чтобы добавить этаж, скопируйте JSON и сцену, задайте другой `floor_id` и путь `floor_data_path`. `target_floor` в `DormInteractable` оставлен для будущих переходов. Следующий этап — таблица сцен по идентификаторам и точки появления у лифта/лестницы; сейчас все переходы честно заблокированы.

Для повторной генерации графики и извлечения XML есть `tools/build_dorm.py`. Запускайте его из корня проекта. Нужен Python и Pillow. Генератор перезаписывает JSON, PNG, настройки запуска и главную сцену; перед запуском сохраните ручные изменения. Обычная игра и редактирование JSON Python не требуют.
