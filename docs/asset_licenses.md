# Источники и лицензии

- Основа: ForlornU / TopdownStarter, https://github.com/ForlornU/TopdownStarter, скачан архив ветки main 31 октября 2026 года. Исходный LICENSE (MIT, ForlornU) сохранён в корне. Исходный README сохранён как `docs/TopdownStarter_README.md`.
- Оригинальные спрайты и библиотека анимаций персонажа, сцена Player, CharacterBase, FSM и состояние движения происходят из этого репозитория и сохранены. Подключение DormPlayer отключает боевой UI и переносит обновление движения в физический цикл; сами исходные системы остаются в проекте.
- m3x6 — Daniel Linssen, https://managore.itch.io/m3x6. Атрибуция из исходного README сохранена. Шрифт остаётся среди ресурсов оригинала; русский интерфейс Dorm Life использует встроенный fallback Godot, а не m3x6. Отдельного лицензионного файла m3x6 в архиве исходника нет; перед коммерческой публикацией следует проверить условия автора для этого оставленного ресурса.
- Новые PNG в `Art/Dorm` созданы программно специально для этого проекта. Код генерации включён. Новые скрипты и эта графика распространяются под MIT; см. `LICENSE_DORM`.
- Звуки Dorm Life синтезируются программно (тон шагов, двери, кнопки и тихий гул). Сторонние звукозаписи в игровую сцену не подключаются. Аудиоресурсы исходного проекта сохранены вместе с исходным MIT и исходной структурой; отдельных дополнительных авторских уведомлений для них в репозитории не обнаружено.
- Пользовательские фотографии и схема находятся в `references`. Они служат референсами, не нанесены на игровой пол и не считаются свободно лицензированными ассетами. Не включайте личные референсы в публичную сборку без проверки прав.
- Портативный движок Godot 4.3 — официальный Windows-релиз Godot Engine, MIT: https://godotengine.org/license/. Его собственные уведомления о сторонних библиотеках доступны в разделе «О программе» редактора. Движок поставляется отдельно от исходников игры.
