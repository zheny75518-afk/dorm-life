# Локальные референсы

Фотографии общежития и пользовательская схема не публикуются в Git.
В рабочей копии игры они остаются на исходном месте.

Для запуска игры референсы не нужны: игровая геометрия уже сохранена в
`Data/Floors/floor08.json`, текстуры — в `Art/Dorm`.

Для повторного запуска `tools/build_dorm.py` понадобится положить сюда
исходную пользовательскую схему `.drawio`. Без неё используйте готовый JSON.
